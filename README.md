# Techmore Swartzit

## How do I install these formulae?

`brew install techmore/swartzit/<formula>`

Or `brew tap techmore/swartzit` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "techmore/swartzit"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
